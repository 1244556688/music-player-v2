01

音樂播放器怎麼使用？

1. 上傳與播放音樂

點擊頂部的 **「上傳音樂」** 按鈕，或直接把電腦裡的 `.mp3` 檔案拖曳到網頁視窗中，系統會自動將其加入播放清單。

2. 播放清單與抽屜

點擊右上角的 **清單圖示** 展開右側抽屜，隨時點擊清單中的任何一首歌即可直接切換播放。

3. 帳號與登出與放大

標題列中央會顯示你目前登入的使用者名稱。點擊左上角紅色按鈕或登出選項即可安全退回登入頁面，點擊綠色按鈕可以全螢幕。

4. 深淺色切換

點擊標題列的 **月亮/太陽圖示**，即可即時在深色模式（Dark Mode）與清爽淺色模式之間切換。

02

背後的技術原理

帳號資料與 localStorage

系統採用瀏覽器的 localStorage，將註冊帳號與密碼以 JSON 格式持久化儲存於本機，讓純靜態網頁也能擁有免後端的輕量級會員驗證機制。

Web Audio API 即時聲頻分析

透過 AudioContext 與 AnalyserNode，將正在播放的音樂音訊即時轉化為頻率數據，再透過 Canvas 繪製出隨著節奏跳動的動態頻譜條。

類 Windows 11 毛玻璃與流光背景

運用 backdrop-filter: blur(20px) 實現現代化毛玻璃特效，背景流光圓球會隨音樂低音強度即時縮放，營造沉浸式體驗。
